# Aquafulness Documentation

This folder documents the theory behind Aquafulness: where the idea comes
from, and the perceptual principles — optic flow and kinesthetic movement —
that the design leans on.

This repository (`aqua-wave-dream`, "Aquafulness Core") is the WebGL/three.js
generation of Aquafulness, built with Lovable. It shares its underlying
theory and design intent with the original Godot-based implementation,
[`drsounds/aquafulness-2028`](https://github.com/drsounds/aquafulness-2028),
where this documentation originates; see that repository's own `docs/` for
notes specific to its Godot implementation.

> **Disclaimer:** Everything in these documents describes design intent
> grounded in the personal experience of the project's creator, together with
> generally known perceptual concepts used as design inspiration. **No
> medical claims are made.** Aquafulness is not a medical device or therapy,
> and no statement here about calm, relaxation or well-being should be read
> as a clinically validated outcome.
