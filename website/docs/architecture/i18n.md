# Internationalisation

- `src/lib/i18n.ts` sets up i18next with five languages:
  `sv` (Svenska), `en` (English), `no` (Norsk bokmål), `da` (Dansk), `fi` (Suomi).
  The chosen language is stored in `aquafulness:lang:v1`.
- Resources are `src/locales/<lang>.json`. **Every new key goes into all five
  files.** Swedish is the primary voice of the app; most UI labels are short
  capitalised Swedish words (`SNÖMÄNGD`, `NORRSKEN`).
- Components use `const { t } = useTranslation()` and `t("dial.env.snowAmount")`.

## Where keys go

| Prefix | Used for |
| --- | --- |
| `dial.<area>.<name>` | Settings rows (`dial.env.snow`, `dial.env.snowAmount`) |
| `options.<list>.<id>` | Option labels from `*_LABEL_KEYS` maps in `settingsShared.ts` |
| `settings.groups.<id>.label` / `.desc` | Settings group names |
| `camera.mode.<mode>` | Movement mode names (SIMMARE, GUNGA, FLYG, FARKOST, BODYFLIGHT) |
| `hud.*` | HUD buttons and stick captions (`hud.joystick.look` = SYNVINKEL in Swedish) |
| Feature blocks | Newer self-contained features have a top-level block: `wind`, `decorations`, `stringLights`, `userScenes`, `timeTravel`, `spacify`, … |

RIDE was renamed from FREAK OUT only in the locales; the code and setting ids
stay `freakOut*`. Rename features the same way: change the strings, keep the
ids.
